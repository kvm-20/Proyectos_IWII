===========================================================
SESION 10 - DOCKER
===========================================================
Necesitas Docker Desktop instalado y abierto.

Desde la raiz del proyecto:

   docker compose up --build

Espera a que diga "Listening at: http://0.0.0.0:5000".
Luego, en otra terminal, carga los datos de ejemplo:

   docker compose exec backend python seed.py

Abre:  http://localhost:8080

Para apagarlo todo:
   docker compose down

Para borrar tambien la base de datos:
   docker compose down -v

===========================================================
SESION 11 - KUBERNETES
===========================================================
Antes: en Docker Desktop entra a Settings -> Kubernetes y
activa "Enable Kubernetes". Espera a que quede en verde.

1) Construir las dos imagenes:

   docker build -t biblioweb-backend:1.0 .
   docker build -t biblioweb-frontend:1.0 ./frontend

2) Desplegar:

   kubectl apply -f k8s/

3) Ver que todo quede corriendo (repite hasta ver Running):

   kubectl get pods -n biblioweb

4) Cargar los datos de ejemplo:

   kubectl exec -n biblioweb deploy/backend -- python seed.py

5) Abrir:  http://localhost:30080

Comandos utiles para la sustentacion:
   kubectl get all -n biblioweb
   kubectl logs -n biblioweb deploy/backend
   kubectl scale -n biblioweb deploy/backend --replicas=3
   kubectl delete -f k8s/      (para borrar todo)
